# 🔍 Project 2: Exploratory Data Analysis (EDA)

## 🎯 Objective
The primary objective of this project was to deeply interrogate the standardized sales dataset. By utilizing advanced Excel functions, descriptive statistics, and dynamic pivot tables, this analysis uncovers critical operational trends, measures customer distributions, and isolates key behavioral anomalies within corporate sales.

---

## 📈 Key Discovery & Analytical Frameworks
Through meticulous analysis of the data records, the following core frameworks and insights were established:

* *Transaction Volume Analysis:* Documented and visualized a comprehensive operational funnel tracking an overall baseline of unique consumer transaction entries to map raw demand.
* *Central Tendency & Basket Metrics:* Isolated and evaluated average order values (AOV) across multiple performance and product segments to baseline typical transactional sizes and purchasing thresholds.
* *Operational Anomalies Uncovered:* Discovered critical frequency spikes and extreme volume trends within order fulfillment metrics—specifically highlighting a significant cluster of cancelled and returned orders impacting revenue flow.
* *Dynamic Categorization:* Structured analytical breakdowns across sales segments, payment methods, and product categories using optimized pivot tables to feed directly into advanced data reporting.
